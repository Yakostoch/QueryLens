# QueryLens

Настольное приложение на PySide6 с локальным сбором показателей PostgreSQL и ОС.
Анализ SQL пока остаётся заглушкой: SQL редактора не выполняется и не проверяется.

## Экспериментальная ветка local-collectors

Установить зависимости в активное окружение: `python -m pip install -r requirements.txt`.
На macOS запуск: `python main.py`. Для проверки Hardware выключить Config,
включить Hardware и на странице «Анализ БД» нажать «Собрать показатели».
Для Config сначала подключить локальную PostgreSQL. Адреса внешних серверов
отклоняются; данные отчёта не сохраняются в историю SQL.

Полный пошаговый план, роли функций и схема: [docs/implementation_plan.md](docs/implementation_plan.md).

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Структура

- `main.py` — точка входа и настройка Qt.
- `app/ui/main_window.py` — главное окно и связь действий интерфейса.
- `app/ui/widgets/sql_editor.py` — редактор SQL с номерами строк.
- `app/ui/widgets/sql_highlighter.py` — подсветка SQL: ключевые слова, функции,
  числа, строки, имена в кавычках, операторы и комментарии. Цвета зависят от темы.
- `app/sql_context.py` — границы SQL-запросов и контекст курсора.
- `app/ui/widgets/history_panel.py` — список, поиск и действия с историей.
- `app/ui/dialog/settings_dialog.py` — панель настроек.
- `app/ui/dialog/connection_dialog.py` — форма подключения к СУБД.
- `app/ui/widgets/database_panel.py` — интерфейс анализа базы данных.
- `app/ui/widgets/tools_panel.py` — выбор Config Analyzer и Hardware Analyzer.
- `app/ui/widgets/toggle_switch.py` — переключатель инструментов.
- `app/ui/theme.py` — цвета и стили светлой и тёмной тем.
- `app/storage/history.py` — SQLite-хранилище запросов и результатов.
- `app/storage/preferences.py` — настройки через QSettings.

Верхняя навигация содержит «SQL», «Подключение», «Анализ БД» и «Инструменты».
«Подключение» открывает диалог PostgreSQL. Для работы требуется `psycopg`:
`python -m pip install "psycopg[binary]"`. Кнопка «Проверить подключение» проверяет
параметры и закрывает пробное соединение. «Подключиться» сохраняет открытое
соединение до переподключения или закрытия приложения. Сборщик использует своё
read-only соединение в рабочем потоке с таймаутом диагностических запросов 5 секунд.
Переключатели Config Analyzer и Hardware Analyzer меняют выбор модулей в интерфейсе
и список на странице «Анализ БД». Выбор действует только до закрытия приложения.
Кнопка «Собрать показатели» запускает выбранные сборщики в QThread; доступна отмена.
Config собирает настройки, статистику и структуру; Hardware — 5 измерений ресурсов ОС.
LLM, планы и 15 проверок SQL будут добавлены следующим этапом.

Каждое нажатие «Анализировать» сохраняет непустой запрос, дату и результат,
если запись истории включена. В списке показаны последние 200 совпадений;
более ранние записи остаются в базе и доступны через поиск. Двойной щелчок
или кнопка «Открыть» восстанавливает SQL и результат. Удаление убирает только
выбранную запись. Текст в редакторе сам по себе не является сохранённым черновиком.

Тонкая салатовая рамка появляется через 500 мс наведения мыши на текст запроса,
только если он завершается `;`. При уходе мыши, вводе текста и прокрутке рамка
исчезает. Наведение не меняет запрос, выбранный текстовым курсором для анализа.
Точка с запятой в строке или комментарии не включает рамку. Запросы разделяются `;`, кроме
разделителей внутри кавычек, комментариев и PostgreSQL dollar-строк. На пробелах
между запросами активен следующий запрос; на пробелах после последнего — последний.
Блоки процедур с внутренними `;` без dollar-кавычек и разделители `GO` / `DELIMITER`
пока не распознаются как единый запрос.

«Анализировать» и Ctrl+Enter отправляют в заглушку и историю только активный
запрос. Ручное выделение имеет приоритет и отправляется точно как выделено.
Реального выполнения в базе нет. В результате показывается отправленный SQL.

После двух букв над строкой ввода появляются подсказки ключевых слов (до шести
видимых вариантов). У верхнего края экрана список размещается снизу, не закрывая
строку ввода. Стрелки выбирают вариант,
Tab дополняет слово, Escape скрывает список, Ctrl+Space вызывает его вручную.
Если дополнения нет, Tab вставляет четыре пробела. В строках, комментариях
и именах в кавычках дополнение отключено.

Ctrl + колёсико над SQL-редактором меняет размер шрифта от 10 до 20 пт.
Размер обновляется также в панели вывода, сохраняется между запусками и
отображается в настройках. Колёсико без Ctrl прокручивает текст.

База `history.sqlite3` находится в каталоге Qt AppLocalDataLocation
(на Windows обычно `%LOCALAPPDATA%/QueryLens/QueryLens`). Настройки темы,
шрифта и записи истории сохраняются через QSettings (на Windows — в реестре
текущего пользователя). При подключении к PostgreSQL параметры подключения
передаются указанному серверу.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки используют временную базу и временные настройки. Снимки интерфейса
в обеих темах сохраняются в `.artifacts/`; окна запускаются в режиме offscreen.
