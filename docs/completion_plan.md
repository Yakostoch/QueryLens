# Завершение QueryLens

## Реализовано

Работают 15 проверок SQL, EXPLAIN и управляемый EXPLAIN ANALYZE, сбор метаданных,
конфигурации PostgreSQL и ресурсов компьютера, краткий результат, история и
экспорт примеров. Диагностика и понятные пояснения формируются правилами.
Подключение к LLM удалено; установка Ollama и весов модели не требуется.

## Что осталось для сдачи

1. Проверить запуск и основные действия на Windows: подключение, анализ,
   ошибку SQL, тайм-аут, отмену, закрытие, историю и экспорт.
2. Зафиксировать проверенные ОС, Python, зависимости и PostgreSQL.
   Проверка одной версии не подтверждает совместимость со всеми версиями.
3. Оценить качество рекомендаций на независимо проверенном наборе, если это
   требуется для курсовой. Сохранённые предложения не становятся эталоном
   автоматически. Ручная разметка не нужна для обычной работы приложения.
4. Описать измеренные сравнения запросов и их ограничения. Равенство результатов
   на текущих данных и разница медиан не гарантируют ускорение на любой базе.
5. Подготовить отчёт, инструкцию и демонстрацию: проблемный запрос, допустимая
   конструкция, хороший запрос и корректный отказ при нехватке данных.

## Подтверждённые проверки на компьютере пользователя

PostgreSQL 18.4, macOS: 131 сценарий, 128 пройдено, 0 ошибок, 3 без выполнения SQL
из-за отсутствия значений параметров. В N+1 проверялся отказ от вывода по одному
запросу, а не обнаружение серии вызовов приложения.

Для двух пар запросов проверено равенство результатов без учёта порядка и
измерены медианы повторных запусков: DISTINCT — 4,52 / 2,21 мс; COUNT / EXISTS —
0,04 / 0,02 мс. Это наблюдения конкретного стенда, не доказательство устойчивого
ускорения всех запросов.
