# Оформление кода

В Python-файлах используются отступы в четыре пробела и строки до 100 символов,
кроме длинных строковых значений. Импорты разделены на стандартную библиотеку,
внешние пакеты и модули приложения. Пояснения и строки документации написаны
по-русски; имена API, идентификаторы полей и SQL сохранены в исходном виде.

Параметры форматирования находятся в `pyproject.toml`. При необходимости
инструменты разработки устанавливаются отдельно от зависимостей приложения:

```bash
python -m pip install black==25.1.0 isort==6.0.1
python -m isort app scripts tests main.py run_querylens.py
python -m black app scripts tests main.py run_querylens.py
```

Для проверки оформления добавьте `--check-only` к isort и `--check` к black.
При обычном запуске приложения эти инструменты не требуются.
